## Recommended task_list

### 1. Stable English and Malayalam URLs

Preserve / as English and add /ml. Use the installed Next.js routing conventions; the proposed implementation places page and root layout under app/[[...locale]] and permits only the two intended paths. Verify the framework’s metadata-file and root-layout behavior during implementation rather than assuming it.

Affected: frontend/src/app/layout.tsx, frontend/src/app/page.tsx, proposed frontend/src/app/[[...locale]]/layout.tsx and page.tsx, frontend/src/components/layout/LanguageProvider.tsx, Navbar.tsx and Footer.tsx; a shared locale helper if required.

Acceptance: both routes return correctly translated content and html lang in the initial server response without JavaScript. URL determines language. Conflicting saved language preferences do not rewrite the selected URL’s content. Language links work for crawlers and visitors, including mobile selection, reload, back/forward and opening a new tab. Unsupported paths return 404. No forced geolocation or browser-language redirects and no new external dependency.

### 2. Consistent localized search metadata

Generate title, description, canonical, en/ml reciprocal alternates, x-default and OG locale for each language. Extend sitemap with both canonical public pages. Localize the schema description but preserve one stable business identity and the owner-confirmed address/phone/map/booking data. Preserve preview noindex behavior.

Affected: moved layout, frontend/src/app/sitemap.ts, frontend/src/components/ResortStructuredData.tsx, frontend/src/data/site.ts and locale helpers only as needed.

Acceptance: raw HTML metadata matches each route; /ml is self-canonical; reciprocal alternate URLs resolve; production sitemap includes exactly the intended pages; deployment previews are non-indexable. No unsupported review/rating/award/offer claims appear in schema. Invalid locale paths cannot enter canonicals, alternates or schema unchecked.

### 3. Visible resort identity and readable location content

Use the natural English heading “Grand Sapphire Resorts in Thankamony, Idukki” with a Malayalam equivalent; retain the slogan as supporting copy. Use only existing confirmed business facts. Keep core location/contact information readable without JavaScript rather than depending on viewport-triggered opacity animation.

Affected: frontend/src/components/sections/HeroSection.tsx, LocationSection.tsx, frontend/src/i18n/en.json and ml.json.

Acceptance: exactly one descriptive H1 per language. Core address/phone/directions agree with schema. No keyword stuffing, invented distances or unsupported amenities. Check no-JavaScript readability including ancestor opacity; check desktop/mobile layout and language selection.

### 4. Test and independent review

Update existing language and SEO tests first to express URL-driven language selection, then implement until they pass. Extend frontend/tests/seo.spec.ts, site-audit.spec.ts and navigation.spec.ts where the behavior is currently tested. Preserve booking/gallery/reservation regressions.

Run dependency audit, deployment checks, lint, production build, typecheck and the full Playwright suite. Exercise production and preview indexing configurations with isolated artifacts. Cover the added routing/locale/metadata behavior with meaningful tests; report any unmeasured aggregate coverage honestly. Obtain independent code review and a security review for dynamic route/input and URL handling. Resolve critical/high findings before the commit gate.

### 5. Commit gate, release, post-deploy validation

Show the exact diff, checks and proposed conventional commit messages at Gate 2. Commit only after the user confirms, as explicitly required by the invoked pipeline. Then publish to the existing Netlify Free project 70743e9b-3641-4571-be10-df35ba261950; use the real production hostname and the documented CLI publish-path normalization. No new hosting project, plan upgrade or domain purchase.

After deployment, verify the published deployment/source and anonymous 200 pages, 404 behavior, HTTPS, metadata/schema/alternates/robots/sitemap, assets, desktop/mobile language navigation and gallery. Capture screenshots and console/network evidence. Attempt a legitimate performance audit once; report unavailable metrics without inventing a score. Retain the existing production deployment 6afeedb42bfdd624da053e35 as the rollback baseline.
